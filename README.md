# Left 4 Dev — Interactive Showcase

Team showcase dạng one-page cho nhóm Left 4 Dev, xây dựng bằng semantic HTML, CSS Grid/Flexbox và JavaScript thuần.

## Thành viên

- Nhữ Mai Gia Long — Nhóm Trưởng
- Trần Khắc Đạt
- Phạm Thành Danh
- Nguyễn Hữu Thanh Trường

## Chạy tại máy

Mở `index.html` trong trình duyệt. Google Fonts, ảnh Unsplash và AOS được tải từ CDN nên cần kết nối Internet để hiển thị đầy đủ.

## Tương tác

- Intro animation cho header và hero; các section xuất hiện theo cuộn bằng AOS.
- Nút trên từng project card mở/đóng phần mô tả chi tiết.
- Menu điều hướng thu gọn trên màn hình nhỏ; CTA có hover và active state.
- Hỗ trợ `prefers-reduced-motion` và fallback hiển thị nội dung khi AOS không tải được.

Xem lựa chọn chuyển động và tư duy UX trong [prompt_logic.md](prompt_logic.md).
